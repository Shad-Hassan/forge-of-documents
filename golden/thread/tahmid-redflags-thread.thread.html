Good afternoon Tahmid Bhai,

You said "there will be many versions of it", and payment "only if the landing page and the globe works". That's the problem.

An employee is paid for their time, however many versions it takes. A contractor is paid for a fixed scope, timeline and price, agreed up front. You're asking for many versions on a contractor's payment terms, which isn't how professional work is commissioned. A mockup, features added message by message and a video that still hasn't come are context sent in pieces, not a scope. And "works" isn't an acceptance criterion.

This is a side project for me, so I need to know exactly how long you'll be in my calendar. Send me the full scope and a calculated timeline for the entire project, including every version, in writing. Not an assumed "two weeks"; you're technical enough to work it out. If writing it up is more than you want to take on, a project planner can do it for you.

With that, I'll tell you whether I can fit it in and what it costs. Without it, I'll pass on this one.
